# Editorial Matte Obsidian Design System

## Overview
A minimalist, high-contrast dark editorial aesthetic matching the "Derek®" design specimen. Matte obsidian surfaces (`#0a0a0a`), razor-sharp 1px hairline dividers, warm off-white typography (`#f3f2ed`), and lime-olive monospace micro-labels (`#a3e635`).

## Core Principles
1. **Zero default Bootstrap borders**: No thick gray container outlines; structure is defined by 1px subtle hairline rules.
2. **Viewfinder profile frame**: Monospace `FIG. 01 / VINCE` framing with geometric corner brackets.
3. **Pill-shaped action buttons**: Seamless pill buttons with subtle hover lift.
